# 发现页功能
来源：2026-10-17 用户截图。页面锚点：顶部“发现”、底部发现选中、稳定功能行；用户可调整可见入口，因此行序不是固定契约。下列位置仅限这张参考帧，实际优先当前文本。

| 控件 | 参考行中心 | 功能与预期核验 |
| --- | --- | --- |
| 朋友圈 | (50%,15%) | 朋友圈动态入口；核对朋友圈页，打开不等于发布 |
| 视频号 | (50%,22%) | 视频号内容入口；核对子页，不顺带播放或创作 |
| 扫一扫 | (50%,29.5%) | 扫码入口；需要相机/码，普通搜索不用此项 |
| 听一听 | (50%,36%) | 音频相关入口；具体子菜单需观察，未要求时不播放 |
| 搜一搜 | (50%,43%) | 微信内容搜索入口；进入后核对搜索页再输入词，不当作首页联系人搜索 |
| 附近的人 | (50%,50.5%) | 附近用户入口；位置授权及实际结果需当前观察 |
| 游戏 | (50%,58%) | 游戏服务入口；具体子项未展示 |
| 小程序 | (50%,65%) | 小程序入口；进入后按当前名称/搜索定位目标 |

每行左侧为图标，中间为标签，右侧箭头表示进入；点击当前标签对应行即可，不要求逐次点击最右箭头。红点、右侧头像/预览属于动态提醒，不进入页面指纹。目标入口缺失时先核对当前页面与可见设置，不用旧坐标点击别的行。导航后只加载本任务需要的子页知识。
