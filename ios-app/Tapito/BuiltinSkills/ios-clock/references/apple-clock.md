# 时钟操作参考
核对日期：2026-10-17；官方网页当前提供 iOS 27 使用手册。官方说明用于理解按钮，当前设备的 UI 决定实际位置，不能从文档虚构坐标。

## 闹钟
[Apple：设定闹钟](https://support.apple.com/zh-cn/guide/iphone/iph2909d3a74/ios)：时钟→闹钟→添加→时间及选项→完成。重复选星期；标签命名；铃声选声音/振动；稍后提醒及其时长控制延迟提醒。编辑已有闹钟可点时间，或先编辑再点时间；时间旁开关用于启停；列表左滑后废纸篓用于移除。普通闹钟和健康中的睡眠起床闹钟是不同流程。

Tapito 执行与核验：
1. 读取现有列表，核对时间、标签、重复和开关，避免重复创建。只在目标不明确时追问。
2. 时间选择器可能是滚轮或可编辑字段：文本可直接输入，滚轮需观察后调整；OCR 数字不能证明当前选中值。核对 12/24 小时制与上午/下午。
3. 保存前核对重复星期，“每天”“工作日”“明天一次”不能相互替代。普通时钟没有由此说明证明的任意日期字段，不声称已设定一个未核验日期。
4. 保存后回列表核对时间/标签/重复及启用状态。开关是状态操作，已处于目标状态时不再点。

## 计时器
[Apple：设定计时器](https://support.apple.com/zh-cn/guide/iphone/iph8241d6b2a/ios)：选择计时器，设时长、标签与结束提示，点击开始。正在运行时可以添加另一个；暂停与继续按钮控制当前计时器；左滑删除。结束提示列表中的“停止播放”用于到时停止媒体，不等于立即停止当前计时。

Tapito 执行与核验：将用户时长换算成小时/分钟/秒并核对字段，不能把分钟输入到小时。开始后观察剩余时间变化与暂停按钮，不能把设置数字或“最近使用”记录当成运行中。暂停后观察暂停状态；删除要核对目标标签/时长，避免移除其他同时运行的计时器。只设置闹钟/计时器不主动试听铃声。
