# 消息中心
来源：用户 2026-10-17 截图；扫帚语义经用户确认。页面锚点：底部消息选中；顶部动态/消息；@我的、评论、赞三行。

| 控件 | 参考位置 | 功能与检查 |
| --- | --- | --- |
| 动态/消息 | 顶部 (41%,10%)/(59%,10%) | 切换通知动态与消息视图；核对选中项 |
| 扫帚 | 顶部 (71%,10%) | 清除私信和群聊的全部未读标记（用户确认），不是删除聊天；需用户请求清未读才执行，检查红点/计数变化，若有确认框按实际范围处理 |
| 气泡＋ | 右上 (94%,10%) | 新消息相关菜单；实际菜单项尚未展示，打开后再判断 |
| 发现群 | 左上 (9%,10%) | 群发现入口；不是已有群会话搜索 |
| @我的 | 第一固定行，中心 y≈16% | 查看提及通知；核对子页标题 |
| 评论 | 第二固定行，中心 y≈24% | 查看评论通知，不是给首页微博发评论 |
| 赞 | 第三固定行，中心 y≈32% | 查看赞通知，不是给当前博文点赞 |
| 服务通知/活动通知/系统通知等 | 下方列表 | 打开对应通知分类；内容和排序变化，按当前标签选择 |
| 私信或群聊会话 | 列表中动态行 | 打开指定会话；核对收件人与群/私聊类型，不凭历史行号选人 |

读消息不等于回复。发私信时按当前会话查找输入框、整段输入并核对提交结果；该参考图未展示私信编辑页，不能从微信或其他页套用坐标。列表里的红点与日期是状态/内容，不作固定定位锚点。不要为完成浏览任务顺手清除未读。
